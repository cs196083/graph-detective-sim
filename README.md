# 그래프 탐정 복습

중학교 정보 Ⅱ. 데이터 수업의 복습용 시뮬레이션입니다. 왜곡된 그래프를 체크리스트 10개 항목으로 점검하고, 상관과 인과를 구분해 신뢰도를 판정합니다.

**바로 가기: https://cs196083.github.io/graph-detective-sim/**

## 구성

1. 사건 접수: 그래프의 주장 쓰기와 첫 투표
2. 기본 조사: 단정 표현, 자료 유형, 출처·기간, 표본 확인
3. 사건 미션 5개: 집단 크기, 상관과 인과, 세로축, 그룹화, 비율 비교
4. 체크리스트 10: ○△× 판정과 위험 요소 TOP 2
5. 최종 판정: 그래프 고치기, 판정, 해석 문장, 활동 기록 복사

급식 만족도 그래프는 수업용 가상 자료입니다. 미션 자료의 수치는 학생 활동지(그림 출처: 통그라미 학생용 활동지)를 따릅니다. 학생의 답은 서버로 전송되거나 저장되지 않습니다.
